STEP 02

Technical Architecture

SOTA 3-Stage Hybrid Screening

A battle-tested pipeline that marries fast local CPU vector retrieval with 70-billion parameter neural reasoning for production-grade candidate matching.

STAGE 01

Deterministic Extraction

PyMuPDF extracts raw text and structure in <50ms. Pydantic v2 models parse candidate entities without OCR latency.

STAGE 02

Dense Vector Search

BAAI/bge-small-en ONNX computes 384-dimensional cosine similarity across all active job postings in <15ms per listing.

STAGE 03

70B Rubric Reasoning

Llama 3.1 70B (NVIDIA DGX Cloud) computes calibrated 1–10 fit scores, rubric breakdowns, and recruiter justifications.
