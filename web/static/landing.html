3-Stage Hybrid Screening Architecture

Engineered to eliminate keyword hallucination and compute objective candidate-job fit scores.

STAGE 01

Deterministic Parsing

Sub-50ms offline PDF text extraction and entity mapping via PyMuPDF. Extracts structured skill matrices and background without cloud exposure.

STAGE 02

Dense Vector Retrieval

Local ONNX-accelerated 384-dimensional dense semantic embedding generation (BAAI/bge-small). Zero-cost local CPU cosine ranking across 1,000+ jobs.

STAGE 03

70B Rubric Reasoning

Deep semantic evaluation via Llama 3.1 70B (NVIDIA NIM). Evaluates 4-pillar rubric breakdowns, skill gaps, and calibrated 1-10 match scores.
