⚙️ Technology

SOTA 3-Stage Hybrid
Screening Architecture

The same pipeline used by top enterprise ATS platforms — built open-source with zero server costs.

3-Stage Hybrid Neural Screening Pipeline

Deterministic extraction → Dense vector retrieval → Multi-dimensional rubric reasoning

Stage 01 — Extraction
Structured Entity Extraction

PDF text layers extracted in <50ms. Pydantic models parse candidate profiles — skills, education, experience, projects — without OCR latency.

PyMuPDF Pydantic v2 FastAPI
Stage 02 — Vector Retrieval
Dense Semantic Embeddings

384-dimensional cosine similarity computed via BAAI/bge-small-en ONNX model. Runs locally on CPU in <15ms with <200MB RAM. Zero API cost.

FastEmbed ONNX Runtime BAAI/bge
Stage 03 — Rubric Reasoning
Multi-Dimensional Scoring

Weighted evaluation: Technical Match (40%), Experience Depth (30%), Domain Relevance (20%), Prerequisites (10%). Outputs calibrated 1-10 scores with justification.

NVIDIA NIM Llama 3.1 70B Structured Output
